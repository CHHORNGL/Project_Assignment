Lightweight Architecture

AgriSystem is architected so that large model weights (7B+ parameters) are hosted in standalone GPU inference environments (Hugging Face ZeroGPU, Railway, or RunPod).

The main Flask web server remains lightweight and snappy (< 200MB RAM), proxying farmer diagnosis prompts securely via HTTPS.

Secure Token Authentication

When deploying your container or Space, pass the generated token as the environment variable INFERENCE_API_KEY.

Authorization: Bearer <YOUR_SECRET_TOKEN>
